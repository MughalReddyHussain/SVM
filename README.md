# VSM SHOWS

A responsive movie discovery website starter for the VSM SHOWS project.

## Included
- Responsive homepage and movie-card layout
- Movie search and genre filter
- Movie detail pop-ups
- Seven requested titles: Sigma, Salaar, Our Fault, Akka, Ranabaali, Thellakaagitham, and Aadarsha Kutumbam

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. After GitHub finishes publishing, open the Pages URL shown in Settings → Pages.

## Important project notes
- The current poster panels are original CSS artwork placeholders, not official movie photographs/posters.
- Replace them with official or properly licensed poster image files before public/commercial use.
- Movie showtimes, seat selection, ticket checkout and payments are not connected yet. The current website is a front-end demo only.
